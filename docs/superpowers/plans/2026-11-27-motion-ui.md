# Motion Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menambah lapisan animasi `motion` di seluruh UI ZerDonghua tanpa mengubah identitas visual, layout, atau perilaku yang ada.

**Architecture:** Satu dependency (`motion`), satu komponen bantu `Reveal`, dan `MotionConfig` di root untuk reduced-motion. Overlay dianimasikan lewat `AnimatePresence` (memerlukan penghapusan guard `if (!isOpen/!slug) return null`). Kartu, hero, header, dan bottom nav memakai `motion` element langsung.

**Tech Stack:** Next 15 App Router, React 19, Tailwind v4, `motion` (`motion/react`), Playwright MCP untuk verifikasi.

**Spec:** `docs/motion-ui.md`

## Global Constraints

- Tidak ada redesign: warna, tipografi, spacing, layout, dan teks tidak diubah.
- Satu-satunya dependency baru: `motion`. Tidak ada UI library, icon, atau font baru.
- Durasi animasi maksimum 0.4s; overlay 0.18–0.22s. Hanya `opacity`/`transform`.
- Semua handler, state, fetching, routing, dan teks tetap sama.
- Proyek tidak punya test runner (hanya `node --test` untuk `src/lib/*.test.ts`). Verifikasi task = dev server + Playwright + `npm run lint` / `npm run build` di task terakhir. Jangan menambah test runner.
- Developer server yang dipakai: `http://127.0.0.1:3100` (port 3000 milik proses lain, jangan disentuh).
- Commit per task, pesan bahasa Indonesia mengikuti riwayat repo.

## Review Focus

- **Guard overlay dihapus**: klik backdrop atau Escape berulang saat animasi exit bisa memanggil `onClose` dua kali atau meninggalkan state terbuka. Cek tiap overlay dengan klik dua kali cepat.
- **Reduced motion**: dengan `prefers-reduced-motion: reduce`, konten harus langsung terlihat penuh (opacity 1, tanpa transform). Animasi yang tersangkut di opacity 0 = bug.
- **Tanpa JS / SSR**: `Reveal` merender `opacity: 0` di HTML awal. Pastikan teks tetap ada di DOM (SEO) dan halaman normal saat JS aktif. Jangan pakai `Reveal` pada konten kritis above-the-fold (SpotlightHero).
- **Section anchor**: nav header men-scroll ke `#popular`, `#latest`, `#ongoing`, `#recommendations`. Wrapper `Reveal` tidak boleh memutus id atau `scroll-margin`.
- **Layout shift**: `whileHover={{ y: -3 }}` tidak boleh digabung dengan class `hover:-translate-y-*` (dua sumber transform). Hapus class lama saat menambah motion.

```tsx
import React from 'react';
import { motion } from 'motion/react';

// Satu animasi reveal dipakai semua section home; `once` supaya tidak
// berkedip saat user scroll naik-turun.
export const Reveal: React.FC<{
  children: React.ReactNode;
  className?: string;
  delay?: number;
}> = ({ children, className, delay = 0 }) => (
  <motion.div
    className={className}
    initial={{ opacity: 0, y: 12 }}
    whileInView={{ opacity: 1, y: 0 }}
    viewport={{ once: true, margin: '0px 0px -60px 0px' }}
    transition={{ duration: 0.4, delay, ease: [0.22, 1, 0.36, 1] }}
  >
    {children}
  </motion.div>
);
```

- [ ] **Step 4: Bungkus root App dengan `MotionConfig`**

Import `{ MotionConfig } from 'motion/react'` di `src/App.tsx`. Bungkus JSX di baris 373 (`<div className="min-h-screen ...">`) beserta seluruh isinya:

```tsx
return (
  <MotionConfig reducedMotion="user">
    <div className="min-h-screen bg-canvas text-ink flex flex-col selection:bg-accent selection:text-white relative">
      ...
    </div>
  </MotionConfig>
);
```
